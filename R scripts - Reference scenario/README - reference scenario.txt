Money as a mechanism of generalized reciprocity: R scripts for the reference simulation with 500 agents in the main manuscript.

The "money_analysis_main.R" script generates the Figures reported in the main manuscript (Figures 2, 3, 4 and 5).

This script works with CSV files produced either by the C++ implementation or by the NetLogo model. The only difference lies in how the data is read from the output directory. The C++ version produces one CSV file per parameter combination in a given experimental batch, with each file capturing the evolution of the model over 30000 ticks (data saved every 250 ticks) across 100 independent runs. In contrast, the NetLogo version outputs a single large CSV file containing all simulations.

For efficiency, we recommend using the C++ version, which is significantly faster. Accordingly, the R script is set up to load the files generated by the C++ code (these are also the ones available in the *Simulation Data* folder). However, once the `all_data` object is loaded —regardless of source — the rest of the analysis proceeds identically, whether the data originates from C++ or NetLogo.
